# Windows Runtime Packaging Design

Date: 2026-07-11

## Decision

The current Windows installer is a source bundle with declared external tools,
not a self-contained media-processing distribution. It ships the exact audited
GPStitch and RoadWatcher CV sources and locks required by the native commands,
while avoiding an unreviewed redistribution of Python, FFmpeg, GDAL, or routing
software.

## Installer Resources

Tauri's explicit resource map installs:

- GPStitch v0.18.0 source, static assets, `pyproject.toml`, `uv.lock`, README,
  release notes, and full GPL-3.0-or-later license;
- the three RoadWatcher CV source modules, `pyproject.toml`, `uv.lock`, and README;
- `runtime-manifest.json` and `THIRD_PARTY_NOTICES.md`.

The CV files are individually whitelisted so generated bytecode/cache files
cannot enter an installer. The GPStitch source comes from the immutable pinned
gitlink. Tests, fixture videos, and `.git` metadata are not packaged.

## Build and Runtime Enforcement

The Rust build script parses the runtime manifest before compiling and fails on
missing component roots/files, mismatched versions/licenses, unsafe resource
paths, or a tool incorrectly marked as redistributed. The Node release verifier
also checks the Tauri source-to-target map and exact GPStitch gitlink.

Native GPStitch/CV commands accept their established logical relative paths. At
runtime these resolve first in development and then under Tauri's packaged
resource directory. Explicit absolute directories remain available for audited
development/test overrides; arbitrary relative paths and traversal are rejected.

## External Prerequisites

The runtime manifest explicitly declares `uv`, FFmpeg, ffprobe, GDAL/OGR,
Valhalla, and OSRM as not distributed. Python 3.12+ must be available before
RoadWatcher prepares versioned environments in app-local data for offline
sidecar execution. The notices explain that a
future embedded runtime requires an exact binary/package and license inventory.

## Verification Evidence

On 2026-07-11 an unsigned debug x64 NSIS installer built successfully. Archive
extraction confirmed non-empty runtime manifest, notices, GPL text, sidecar
sources, and locks, with no Python cache artifacts.

## Deferred Release Work

- Choose between a fully inventoried embedded runtime and retaining the
  implemented user-triggered environment preparation/preflight model.
- Acquire the Windows signing identity and execute the documented clean-machine
  release gate. Synchronized release versioning, explicit manual-update policy,
  unsigned/stable claim rejection, and the installed startup-smoke tool are now
  implemented.
- Run the live matcher smoke. Real installed-GDAL, CV model/video, GPStitch, and
  FFmpeg smokes now pass; temporary binaries/weights remain external and are not
  packaged.
