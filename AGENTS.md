# RoadWatcher agent handoff

Start with `docs/STATUS.md`, then read `docs/ARCHITECTURE.md` and the current milestone file. Keep functional changes in separate Conventional Commits and update `docs/STATUS.md` before handing work off.

Prefer the mature dependencies recorded in `docs/DEPENDENCIES.md`. Do not create a custom control unless the capability cannot be composed from Avalonia controls or the approved media/map libraries. The only planned custom control is the virtual multi-track timeline.

Store milestone screenshots under `docs/milestones/<milestone>/` and include the viewport and tested state in that milestone's README.
